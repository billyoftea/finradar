    docker ps -a | grep -E "(nitter|wechat|finradar)"
    
    应该看到 4 个容器都是 "Up" 状态：
    ✅ finradar-market              (自动调度以下任务)
       ⏱  每30分钟 → 金融市场数据 (A股/期货/贵金属/加密货币) + NewsNow热榜
       🌅 每天07:00 → Twitter (12个账号) + 微信公众号 (67个) [早报]
       🌇 每天19:00 → Twitter + 微信公众号 [晚报]
    
    ✅ wechat-article-exporter      (微信文章服务, 端口3001)
    ✅ nitter                        (Twitter RSS服务, 端口8080)
    ✅ nitter-redis                  (Redis缓存数据库, nitter依赖它)

    💡 为什么有 nitter 和 nitter-redis 两个容器？
       - nitter: Twitter RSS 主服务（你访问的是这个）
       - nitter-redis: Redis 数据库（nitter 用它缓存数据，提高速度）
       它们是配套使用的，类似于"应用程序+数据库"的关系
    
    💡 wechat-article-exporter 显示 (unhealthy) 是正常的
       只要状态是 "Up" 就可以使用

    问题1: 容器没有运行？
    ────────────────────────────────────────────────
    # 检查容器状态
    docker ps -a | grep finradar-market
    
    # 如果显示 "Exited"，重启容器
    cd /home/ubuntu/finradar/docker
    docker compose -f docker-compose-market.yml up -d


    问题2: Twitter HTTP 429 错误 (速率限制)
    ────────────────────────────────────────────────
    # 更新 Twitter token
    ./scripts/update-twitter-token.sh


    问题3: 微信公众号抓取失败
    ────────────────────────────────────────────────
    # 方法1: 更新登录密钥
    ./scripts/update-wechat-key.sh
    
    # 方法2: 重新登录（用浏览器打开）
    http://13.212.190.29:3001


    问题4: 查看详细错误日志
    ────────────────────────────────────────────────
    # 查看最近100行日志
    docker logs finradar-market --tail 100
    
    # 实时监控日志（按 Ctrl+C 退出）
    docker logs finradar-market -f


    问题5: 容器需要重新构建？
    ────────────────────────────────────────────────
    cd /home/ubuntu/finradar
    docker build -f docker/Dockerfile.market -t finradar-market:latest .
    cd docker
    docker compose -f docker-compose-market.yml up -d --force-recreate

│  🔍 Docker 基础命令速查                                       │
└─────────────────────────────────────────────────────────────┘

    查看所有容器:              docker ps -a
    查看运行中的容器:          docker ps
    启动容器:                  docker start <容器名>
    停止容器:                  docker stop <容器名>
    重启容器:                  docker restart <容器名>
    查看日志:                  docker logs <容器名>
    进入容器内部:              docker exec -it <容器名> bash
    
    示例：
    docker logs finradar-market --tail 50   # 查看最新50行日志
    docker restart finradar-market          # 重启市场追踪容器
