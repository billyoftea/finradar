finradar 快速开始（本地优先）

1) 初始化环境（首次）
./scripts/local.sh setup

2) 安装定时任务（08:00/20:00 报告 + 每30分钟市场/热榜）
./scripts/local.sh cron-install

3) 单次测试
./scripts/local.sh run social
./scripts/local.sh report evening

4) 查看状态
./scripts/local.sh status

-----------------------------
可选：Docker 方式
-----------------------------

构建并启动（含社交源容器）：
./run.sh build
./run.sh start all

只启主服务，不拉起社交源：
./run.sh start all --no-sources

查看日志：
./run.sh logs

-----------------------------
微信登录说明
-----------------------------

如果微信抓取为空，请先登录 wechat-exporter：
1. 打开 http://127.0.0.1:3001
2. 微信扫码登录
3. 更新 auth key（config/config.yaml 的 wechat.auth_key，或 WECHAT_AUTH_KEY 环境变量）

- README.local.md
