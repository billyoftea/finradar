## 功能概述

每日市场追踪服务自动抓取以下数据源，生成综合市场报告：

| 数据源 | 说明 | 依赖服务 |
|-------|------|---------|
| 🇨🇳 A股市场 | 上证、深证、创业板等指数 | 无 |
| 🥇 贵金属 | 黄金、白银价格 | 无 |
| ₿ 加密货币 | BTC、ETH、SOL 等 | 无 |
| 📈 期货市场 | 商品期货数据 | 无 |
| 💻 GitHub | 热门开源项目 | 无 |
| 🐦 Twitter | 财经/加密 KOL 动态 | Nitter 实例 |
| 📱 微信公众号 | 财经媒体文章 | wechat-article-exporter |

## 快速开始

### 前置要求

- Ubuntu 20.04+ 服务器
- Docker 和 Docker Compose
- Git

### 一键部署（最小化配置）

```bash
# 1. 克隆项目
git clone git@github.com:billyoftea/finradar.git
cd finradar

# 2. 启动基础服务（不含 Twitter 和微信）
cd docker
sudo docker compose -f docker-compose-market.yml up -d

# 3. 查看运行日志
sudo docker logs finradar-market --tail 100
```

> ⚠️ 最小化配置下，Twitter 和微信公众号数据将为空。如需完整功能，请继续阅读下方详细部署步骤。

## 详细部署步骤

### 第一步：部署 Nitter（Twitter 数据源）

Nitter 是 Twitter 的开源替代前端，用于获取 Twitter RSS 订阅。

```bash
cd finradar/fin_module/nitter

# 启动 Nitter 服务
sudo docker compose up -d

# 验证服务运行
curl http://localhost:8080/elonmusk/rss
```

#### 配置 Twitter Token

1. **在浏览器中登录 Twitter** (https://twitter.com)

2. **获取 Cookie**:
   - 按 `F12` 打开开发者工具
   - 切换到 `Application` → `Cookies` → `https://twitter.com`
   - 找到以下两个值：
     - `auth_token`
     - `ct0`

3. **更新配置文件**:
   ```bash
   # 编辑 sessions.jsonl
   nano fin_module/nitter/sessions.jsonl
   ```
   
   文件内容格式：
   ```json
   {"kind": "cookie", "auth_token": "你的auth_token值", "ct0": "你的ct0值", "id": "你的Twitter用户ID"}
   ```

4. **重启 Nitter 服务**:
   ```bash
   cd fin_module/nitter
   sudo docker compose restart
   ```

---

### 第二步：部署微信公众号服务

wechat-article-exporter 用于抓取微信公众号文章。

```bash
cd finradar/fin_module/wechat-article

# 启动服务
sudo docker compose up -d

# 验证服务运行
curl http://localhost:3001/
```

#### 登录并获取 Auth Key

1. **访问服务界面**:
   - 打开浏览器访问: `http://你的服务器IP:3001`
   - 使用微信扫描二维码登录

2. **获取 Auth Key**:
   ```bash
   # 登录成功后，查看 cookie 目录
   ls fin_module/wechat-article/data/kv/cookie/
   
   # 输出类似：03a7d7d5c19449879ccebbd5f1a4947f
   # 这个文件名就是你的 auth_key
   ```

3. **更新配置文件**:
   ```bash
   nano config/config.yaml
   ```
   
   找到 `wechat` 部分，更新 `auth_key`:
   ```yaml
   wechat:
     enabled: true
     service_url: "http://你的服务器内网IP:3001"
     auth_key: "你的auth_key值"  # 从 cookie 目录获取的文件名
   ```

---

### 第三步：更新主配置文件

编辑 `config/config.yaml`，配置服务地址：

```yaml
# Twitter/Nitter 配置
twitter:
  enabled: true
  nitter_instance: "http://你的服务器内网IP:8080"
  accounts:
    finance:
      - "unusual_whales"
      - "WatcherGuru"
      # ... 更多账号

# 微信公众号配置
wechat:
  enabled: true
  service_url: "http://你的服务器内网IP:3001"
  auth_key: "你的auth_key"
  accounts:
    finance:
      - "财联社"
      - "财经杂志"
      # ... 更多公众号
```

> 💡 **提示**: 服务器内网 IP 可通过 `hostname -I` 获取

---

### 第四步：启动市场追踪服务

```bash
cd finradar

# 构建 Docker 镜像
sudo docker build -f docker/Dockerfile.market -t finradar-market:latest .

# 启动服务
cd docker
sudo docker compose -f docker-compose-market.yml up -d

# 查看日志验证
sudo docker logs finradar-market --tail 150
```

## 密钥配置与更新

### 🔑 两个关键密钥

| 密钥 | 用途 | 有效期 | 位置 |
|-----|------|-------|------|
| **Twitter Token** | Nitter 访问 Twitter API | 约 30-90 天 | `fin_module/nitter/sessions.jsonl` |
| **微信 Auth Key** | 访问微信公众号 API | 约 4 天 | `config/config.yaml` 中的 `wechat.auth_key` |

---

### 🐦 Twitter Token 更新

#### 什么时候需要更新？

当日志出现以下错误时：
```
[sessions] no sessions available for API
HTTP 429 from http://xxx:8080
```

#### 方法一：使用一键更新脚本（推荐）

```bash
cd finradar

# 运行脚本，按提示输入 auth_token 和 ct0
./scripts/update-twitter-token.sh

# 或直接传入参数
./scripts/update-twitter-token.sh "你的auth_token" "你的ct0"
```

#### 方法二：手动更新

1. **获取新 Token**:
   - 登录 https://twitter.com
   - F12 → Application → Cookies
   - 复制 `auth_token` 和 `ct0` 值

2. **更新配置**:
   ```bash
   # 编辑 sessions.jsonl
   nano fin_module/nitter/sessions.jsonl
   
   # 更新为新的 token
   {"kind": "cookie", "auth_token": "新的auth_token", "ct0": "新的ct0", "id": "你的用户ID"}
   ```

3. **重启服务**:
   ```bash
   cd fin_module/nitter
   sudo docker compose restart
   
   # 验证
   curl http://localhost:8080/elonmusk/rss | head -20
   ```

---

### 📱 微信 Auth Key 更新

#### 什么时候需要更新？

当日志出现以下错误时：
```
搜索公众号失败: 认证信息无效
微信公众号文章抓取完成，共 0 篇
```

或者距离上次登录超过 **4 天**。

#### 方法一：使用一键更新脚本（推荐）

```bash
cd finradar

# 先在浏览器中登录微信服务（扫码）
# 访问: http://你的服务器IP:3001

# 然后运行脚本，自动获取最新 key 并更新
./scripts/update-wechat-key.sh
```

脚本会自动：
1. 从 cookie 目录找到最新的 auth_key
2. 更新 config.yaml
3. 重建并重启 Docker 服务

#### 方法二：手动更新

1. **重新登录微信服务**:
   - 访问 `http://你的服务器IP:3001`
   - 微信扫码登录

2. **获取新的 Auth Key**:
   ```bash
   # 查看 cookie 目录，找最新的文件
   ls -lt fin_module/wechat-article/data/kv/cookie/
   
   # 最新的文件名就是新的 auth_key
   ```

3. **更新配置**:
   ```bash
   nano config/config.yaml
   
   # 更新 wechat.auth_key 为新值
   ```

4. **重建并重启服务**:
   ```bash
   cd finradar
   sudo docker build -f docker/Dockerfile.market -t finradar-market:latest .
   
   cd docker
   sudo docker compose -f docker-compose-market.yml down
   sudo docker compose -f docker-compose-market.yml up -d
   ```

---

### ⏰ 建议的更新周期

| 密钥 | 建议更新周期 | 自动化建议 |
|-----|------------|-----------|
| Twitter Token | 每 30 天检查一次 | 设置日历提醒 |
| 微信 Auth Key | 每 3 天更新一次 | 设置日历提醒 |

> 💡 **小技巧**: 可以设置 cron 任务每天检查日志中是否有认证错误

## 常见问题

### Q: 如何查看服务运行状态？

```bash
# 查看所有容器状态
sudo docker ps

# 查看市场服务日志
sudo docker logs finradar-market --tail 100

# 查看 Nitter 日志
sudo docker logs nitter --tail 50

# 查看微信服务日志
sudo docker logs wechat-article-exporter --tail 50
```

### Q: 如何手动触发一次数据抓取？

```bash
sudo docker exec finradar-market python -m finradar
```

### Q: 数据保存在哪里？

- 报告文件: `output/market/market_report_YYYYMMDD.txt`
- JSON 数据: `output/market/market_data_YYYYMMDD.json`

### Q: 如何修改抓取频率？

编辑 `docker/entrypoint-market.sh`，修改 cron 表达式：
```bash
# 默认每 30 分钟执行一次
CRON_SCHEDULE="${CRON_SCHEDULE:-*/30 * * * *}"

# 改为每小时
CRON_SCHEDULE="${CRON_SCHEDULE:-0 * * * *}"
```

### Q: AWS 安全组需要开放哪些端口？

| 端口 | 服务 | 说明 |
|-----|------|------|
| 3001 | 微信服务 | 用于扫码登录 |
| 8080 | Nitter | 可选，用于调试 |
