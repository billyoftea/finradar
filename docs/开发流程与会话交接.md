# 开发流程与会话交接（finradar）

## 1. 目标
- 保证每次改动都有连续 Git 历史。
- 保证会话重开后，能快速恢复“当前进展 + 下一步意图”。

## 2. 推荐流程
1. 拉取并查看当前状态：`git status --short`
2. 实现一个完整小功能（不要过大）。
3. 运行最小验证（如 `./.venv/bin/python -m py_compile ...` 或一条关键命令）。
4. 提交 Git（一个功能一个 commit）。
5. 记录会话 checkpoint（见第 3 节）。

## 3. 会话 checkpoint
- 脚本：`scripts/dev_checkpoint.sh`
- 作用：把“当前意图、下一步、工作区状态、最近提交”写入 `docs/SESSION_CHECKPOINT.md`。

示例：

```bash
./scripts/dev_checkpoint.sh "增强早晚报上下文与联网检索" "下一步优化检索关键词与来源质量"
```

## 4. 提交建议
- 提交信息建议：
  - `feat(report): ...`
  - `fix(report): ...`
  - `docs(process): ...`
- 每次 commit 尽量只包含一个主题，便于回滚和续做。

## 5. 重开会话时怎么继续
1. 先让 Agent 读取：`docs/开发流程与会话交接.md`
2. 再读取：`docs/SESSION_CHECKPOINT.md`（最后一个 checkpoint）
3. 最后执行：`git status --short` + `git log --oneline -n 10`

这样可以在新会话中快速恢复上下文并继续开发。
