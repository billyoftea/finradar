## 配置文件说明

所有配置都在 `config/config.yaml` 文件中，主要分为以下几个部分：

```yaml
# 1. Twitter/Nitter 配置
twitter:
  enabled: true
  nitter_instance: "http://172.31.42.175:8080"
```

## Twitter 账号配置

### 配置位置

`config/config.yaml` → `twitter.accounts`

### 配置格式

按分类组织 Twitter 账号：

```yaml
twitter:
  enabled: true
  nitter_instance: "http://你的IP:8080"
  
  # 每个用户最多获取的推文数
  max_tweets_per_user: 10
  
  # 按分类组织账号
  accounts:
    # 财经类
    finance:
      - "unusual_whales"    # 异常鲸鱼 - 期权数据
      - "WatcherGuru"       # 快讯
      - "zerohedge"         # 财经评论
      
    # 加密货币类
    crypto:
      - "whale_alert"       # 大额转账监控
      - "cz_binance"        # 币安创始人
      - "VitalikButerin"    # 以太坊创始人
      - "DefiLlama"         # DeFi 数据
      
    # AI/科技类
    tech:
      - "elonmusk"          # 马斯克
      - "sama"              # OpenAI CEO
      - "OpenAI"            # OpenAI 官方
      - "ylecun"            # Meta AI 负责人
```

### 添加新账号

1. 确定账号分类（finance/crypto/tech 或自定义）
2. 添加 Twitter 用户名（不带 @）
3. 重建 Docker 镜像使配置生效

```bash
# 编辑配置
nano config/config.yaml

# 重建并重启
sudo docker build -f docker/Dockerfile.market -t finradar-market:latest .
cd docker && sudo docker compose -f docker-compose-market.yml restart
```

## 微信公众号配置

### 配置位置

`config/config.yaml` → `wechat.accounts`

### 配置格式

```yaml
wechat:
  enabled: true
  service_url: "http://你的IP:3001"
  auth_key: "你的auth_key"
  timeout: 30
  
  # 文章全文抓取配置
  fetch_content: true                   # 是否抓取文章全文内容
  content_delay: 0.5                    # 抓取全文之间的延迟（秒）
  
  # 每个公众号获取的文章数
  max_articles_per_account: 20
  
  # 时间过滤：只获取最近 N 小时的文章（默认24小时）
  max_age_hours: 24
  
  # 按分类组织公众号
  accounts:
    # 财经媒体
    finance:
      - "财联社"
      - "财经杂志"
      - "每日经济新闻"
      - "Wind万得"
      - "券商中国"
      - "中国证券报"
      
    # 加密货币
    crypto:
      - "链捕手ChainCatcher"
      - "吴说Real"
      - "Web3小律"
      
    # 科技资讯
    tech:
      - "36氪"
      - "钛媒体"
      - "新智元"
      - "机器之心"
      - "晚点LatePost"
      
    # 量化/数据
    quant:
      - "量化投资与机器学习"
      - "LLMQuant"
      - "QuantML"
```

### 添加/修改公众号

直接编辑 `config/config.yaml` 中的 `wechat.accounts` 部分：

```bash
# 编辑配置
nano config/config.yaml

# 在对应分类下添加公众号名称（必须是公众号的准确名称）
# 例如在 finance 分类下添加：
#   - "华尔街见闻"

# 重建并重启
sudo docker build -f docker/Dockerfile.market -t finradar-market:latest .
cd docker && sudo docker compose -f docker-compose-market.yml restart
```

### 如何查找公众号准确名称？

1. 在微信中搜索公众号
2. 进入公众号主页
3. 点击右上角 `...` → `更多资料`
4. 复制「名称」字段的准确内容

## 时间过滤配置

### 功能说明

时间过滤功能允许你只获取指定时间范围内的文章，避免重复抓取旧内容。

### 配置参数

```yaml
wechat:
  # 时间过滤：只获取最近 N 小时的文章
  max_age_hours: 24    # 默认24小时
```

### 配置示例

| 配置值 | 说明 |
|--------|------|
| `max_age_hours: 24` | 只抓取过去 24 小时的文章（默认） |
| `max_age_hours: 12` | 只抓取过去 12 小时的文章 |
| `max_age_hours: 48` | 抓取过去 48 小时（2天）的文章 |
| `max_age_hours: 0` | 不限制时间，抓取所有文章 |

### 工作原理

1. 从每个公众号获取最新的 `max_articles_per_account` 篇文章
2. 根据文章的 `publish_time`（发布时间）进行过滤
3. 只保留 `发布时间 >= 当前时间 - max_age_hours` 的文章
4. 按发布时间倒序排列（最新的在前）
5. 最多返回 50 篇文章

### 使用建议

- **实时监控**：设置为 `12` 或 `24` 小时
- **每日汇总**：设置为 `24` 小时
- **周报汇总**：设置为 `168`（7天 × 24小时）
- **调试测试**：设置为 `0` 不限制

## 全文抓取配置

### 功能说明

全文抓取功能可以获取微信公众号文章的完整正文内容，而不仅仅是标题和摘要。

### 配置参数

```yaml
wechat:
  # 是否抓取文章全文内容（会增加抓取时间）
  fetch_content: true
  
  # 抓取每篇文章全文之间的延迟（秒），避免被封
  content_delay: 0.5
```

### 配置说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `fetch_content` | `true` | 是否启用全文抓取 |
| `content_delay` | `0.5` | 每篇文章抓取间隔（秒） |

### 注意事项

1. **抓取时间增加**：启用全文抓取后，每篇文章需要额外请求微信服务器，抓取时间会显著增加
2. **延迟设置**：建议保持 `content_delay: 0.5` 或更高，避免请求过于频繁被封禁
3. **内容格式**：抓取的全文为纯文本格式，已去除 HTML 标签

### 输出格式

启用全文抓取后，JSON 输出中会包含 `content` 字段：

```json
{
  "articles": [
    {
      "title": "文章标题",
      "author": "作者",
      "account_name": "公众号名称",
      "publish_time": "2026-02-03T16:05:29",
      "url": "https://mp.weixin.qq.com/s/xxx",
      "digest": "摘要",
      "content": "文章全文内容..."
    }
  ]
}
```

### 禁用全文抓取

如果只需要文章标题和链接，可以禁用全文抓取以加快速度：

```yaml
wechat:
  fetch_content: false    # 禁用全文抓取
```

## API 接口说明

### 微信公众号 API

服务地址: `http://你的IP:3001`

#### 1. 搜索公众号

```bash
# 请求
curl -s "http://IP:3001/api/public/v1/account?keyword=财联社&size=5" \
  -H "X-Auth-Key: 你的auth_key"

# 响应
{
  "base_resp": {"ret": 0, "err_msg": "ok"},
  "list": [
    {
      "fakeid": "Mzg5MzEyNzEwNQ==",
      "nickname": "财联社",
      "alias": "cailianpress",
      "signature": "财联社是..."
    }
  ]
}
```

#### 2. 获取文章列表

```bash
# 请求（需要先通过搜索获取 fakeid）
curl -s "http://IP:3001/api/public/v1/article?fakeid=Mzg5MzEyNzEwNQ==&size=10" \
  -H "X-Auth-Key: 你的auth_key"

# 响应
{
  "base_resp": {"ret": 0, "err_msg": "ok"},
  "articles": [
    {
      "title": "文章标题",
      "link": "https://mp.weixin.qq.com/s/xxx",
      "create_time": 1706956800,
      "digest": "文章摘要...",
      "author_name": "作者"
    }
  ]
}
```

#### 3. 验证 Auth Key

```bash
curl -s "http://IP:3001/api/public/v1/authkey" \
  -H "X-Auth-Key: 你的auth_key"

# 有效返回
{"code": 0, "data": "你的auth_key"}

# 无效返回
{"code": -1, "msg": "AuthKey not found"}
```

### Nitter (Twitter) API

服务地址: `http://你的IP:8080`

#### 获取用户 RSS

```bash
# 请求
curl -s "http://IP:8080/elonmusk/rss"

# 返回 XML 格式的 RSS Feed
<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0">
  <channel>
    <title>Elon Musk / @elonmusk</title>
    <item>
      <title>推文内容...</title>
      <pubDate>Mon, 03 Feb 2026 12:00:00 GMT</pubDate>
    </item>
  </channel>
</rss>
```

## 自定义报告内容

### 报告输出位置

- 文本报告: `output/market/market_report_YYYYMMDD.txt`
- JSON 数据: `output/market/market_data_YYYYMMDD.json`

### 报告包含内容

报告按以下顺序展示数据：

1. 🇨🇳 A股市场 - 主要指数涨跌
2. 🥇 贵金属 - 黄金白银价格
3. ₿ 加密货币 - BTC/ETH/SOL
4. 📈 期货市场 - 商品期货
5. 💻 GitHub 趋势 - 热门项目
6. 🐦 Twitter 热点 - KOL 动态
7. 📱 微信公众号 - 文章列表

### 禁用某个数据源

在 `config/config.yaml` 中设置 `enabled: false`：

```yaml
twitter:
  enabled: false  # 禁用 Twitter

wechat:
  enabled: false  # 禁用微信公众号
```

### 调整抓取频率

编辑 `docker/entrypoint-market.sh`：

```bash
# 默认每 30 分钟
CRON_SCHEDULE="${CRON_SCHEDULE:-*/30 * * * *}"

# 每小时整点
CRON_SCHEDULE="${CRON_SCHEDULE:-0 * * * *}"

# 每天早上 8 点
CRON_SCHEDULE="${CRON_SCHEDULE:-0 8 * * *}"
```

## Python 代码调用示例

如果需要在自己的代码中调用：

### 抓取微信公众号文章

```python
import asyncio
from finradar.market.fetcher.wechat_article import WechatArticleFetcher

async def main():
    fetcher = WechatArticleFetcher(
        base_url="http://172.31.42.175:3001",
        auth_key="你的auth_key"
    )
    
    # 搜索公众号
    accounts = await fetcher.search_accounts("财联社", limit=1)
    print(f"找到公众号: {accounts[0].name}")
    
    # 获取文章
    articles = await fetcher.get_articles(
        fakeid=accounts[0].fakeid,
        count=10,
        account_name=accounts[0].name
    )
    
    for article in articles:
        print(f"[{article.publish_time}] {article.title}")
    
    await fetcher.close()

asyncio.run(main())
```

### 抓取 Twitter 动态

```python
import asyncio
from finradar.market.fetcher.nitter_rss import NitterRSSFetcher

async def main():
    fetcher = NitterRSSFetcher(
        nitter_instance="http://172.31.42.175:8080"
    )
    
    # 获取单个用户推文
    tweets = await fetcher.fetch_user_tweets("elonmusk", max_tweets=5)
    
    for tweet in tweets:
        print(f"[@{tweet.author}] {tweet.content[:100]}...")
    
    await fetcher.close()

asyncio.run(main())
```
