# 每日市场追踪使用指南（当前版本）

## 1. 核心命令

### 1.1 本地模式（推荐）

```bash
./scripts/local.sh setup
./scripts/local.sh run all
./scripts/local.sh report auto
```

### 1.2 Docker 模式（可选）

```bash
./run.sh build
./run.sh start all
./run.sh logs
```

## 2. 运行模式

`python -m finradar --mode <mode>`

- `all`: 全部抓取
- `news`: 热榜新闻
- `market`: 市场数据（A股 + Yahoo Finance 全球股票 + 贵金属 + 期货 + 加密 + GitHub）
- `social`: Twitter + 微信公众号

等价快捷命令：
```bash
./scripts/local.sh run all
./scripts/local.sh run social
```

## 3. 报告生成

```bash
./scripts/local.sh report morning
./scripts/local.sh report evening
./scripts/local.sh report evening 20260211
```

底层脚本：
```bash
python3 scripts/generate_report.py --type morning
python3 scripts/generate_report.py --type evening
# 手动指定联网检索关键词（逗号分隔）
python3 scripts/generate_report.py --type evening --keywords "A股,美股,比特币,AI芯片"
# 关闭联网检索补充
python3 scripts/generate_report.py --type evening --no-web-context
```

输出目录：
- `output/report/daily_YYYYMMDD_morning.md`
- `output/report/daily_YYYYMMDD_evening.md`

报告增强说明：
- 自动拼接“前 1-2 天多期摘要+跟踪清单”作为上下文（默认最多 3 期，可用环境变量调节）。
- 连续性控制变量：
  - `REPORT_CONTEXT_LOOKBACK_DAYS`（默认 `2`）
  - `REPORT_CONTEXT_MAX_REPORTS`（默认 `3`）
- 自动执行联网检索补充（Google News RSS），用于解释“为什么会这样”。
- 自动输出“投机方向（超短）”提示（默认 2 条方向 + 1 条风控纪律）。
- 微信公众号登录异常/凭据超时会在报告顶部生成“🚨 数据源健康提醒”，同步到 Notion 后可直接看到。
- 自动输出“🧪 引用匹配校验”，用于验证 AI 结论与脚注链接是否完成对齐。
- 引用匹配阈值变量：`AI_CITATION_MIN_SCORE`（默认 `5`）、`AI_CITATION_WARN_SCORE`（默认 `7`）。
- AI 输出结构固定为：`Summary` + 分段拆解（市场、宏观社会、科技、明日观察）。

Notion 合并时间线（同日早晚报合一页）：
- 默认启用：`./scripts/local.sh notion-push evening 20260213`
- 临时关闭：`./scripts/local.sh notion-push evening 20260213 --no-merge-daily`
- 环境变量可控：`NOTION_MERGE_DAILY=0/1`

## 4. 社交抓取说明

### 4.1 Twitter

当前输出包含两部分：
- 关注账号推文
- 关键词热门讨论推文（高互动过滤）

配置位置：
- `config/config.yaml` -> `twitter.*`
- `config/config.yaml` -> `yahoo_stock.*`（可自定义全球股票 watchlist）
- `config/config.yaml` -> `report.speculation.*`（控制投机提示开关和条数）
- `config/config.yaml` -> `wechat.login_reminder_days`（默认 4 天，超阈值会在报告/Notion 顶部提示重新扫码）

### 4.2 微信公众号

当前输出包含两部分：
- 关注公众号文章
- 热门文章（跨公众号）

可选抓正文：
- `wechat.fetch_content: true`

注意：公众号服务需要有效登录态（扫码）。

## 5. 定时任务

安装：
```bash
./scripts/local.sh cron-install
```

策略：
- 每 30 分钟：市场 + 热榜
- 08:00：社交 + 早报
- 20:00：社交 + 晚报

查看：
```bash
./scripts/local.sh status
```

移除：
```bash
./scripts/local.sh cron-remove
```
