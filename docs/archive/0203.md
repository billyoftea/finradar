## 7. 配置编辑指南 📖

### 7.1 如何编辑 Twitter/Nitter 关注账号

编辑 `config/config.yaml` 文件中的 `twitter.accounts` 部分：

```yaml
twitter:
  enabled: true
  nitter_instance: "http://localhost:8080"  # 自建 Nitter 实例地址
  
  accounts:
    crypto:                    # 加密货币分类
      - "VitalikButerin"       # 以太坊创始人
      - "cz_binance"           # Binance CEO
      - "你想添加的账号"       # 添加新账号
    tech:                      # 科技分类
      - "elonmusk"
      - "sama"
    finance:                   # 金融分类
      - "MacroAlf"
  
  max_tweets_per_user: 10      # 每个账号获取的推文数量
```

**注意**：
- 账号名是 Twitter 用户名（@ 后面的部分）
- 可以新增分类，如 `ai`、`news` 等
- 修改后无需重启服务，下次执行时自动生效

### 7.2 如何编辑微信公众号关注列表

编辑 `config/config.yaml` 文件中的 `wechat.accounts` 部分：

```yaml
wechat:
  enabled: true
  service_url: "http://localhost:3001"  # 导出服务地址
  
  accounts:
    finance:                   # 财经分类
      - "华尔街见闻"
      - "财联社"
      - "你想添加的公众号"     # 添加新公众号
    crypto:                    # 加密货币分类
      - "PANews"
      - "巴比特资讯"
    tech:                      # 科技分类
      - "36氪"
      - "新智元"
  
  max_articles_per_account: 20  # 每个公众号获取的文章数量
  max_age_days: 3              # 只获取最近 N 天的文章
```

**注意**：
- 使用公众号的显示名称（不是微信号）
- 需要先在 http://localhost:3001 扫码登录
- 修改后无需重启服务，下次执行时自动生效
